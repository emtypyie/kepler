Auto-Start Setup

Configure Kepler to start automatically when your system boots.

Windows (PowerShell as Admin)
powershell -ExecutionPolicy Bypass -File backend\setup\windows.ps1
Linux
chmod +x backend/setup/linux.sh && sudo ./backend/setup/linux.sh
macOS
chmod +x backend/setup/macos.sh && ./backend/setup/macos.sh
