Download ediary Backend

Run the backend locally to use ediary on your machine.

🐧 Linux / Unix

Version 1.0.0

Download .tar.gz 
tar -xzf ediary-linux-v1.0.0.tar.gz
cd ediary-backend
chmod +x setup.sh
./setup.sh

🪟 Windows

Version 1.0.0

Download .zip 
Expand-Archive ediary-win-v1.0.0.zip -DestinationPath .
cd ediary-backend
.\setup.bat
