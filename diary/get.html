Install Kepler Backend

Run the backend locally to use ediary, pyieOS, and all Kepler services.

v2.0.0
Download Latest

Portable · 27 KB · Windows / Linux / macOS

One-Liner Install

Windows powershell 
curl -fsSL https://kepler.emtypyie.in/curler/ps1 | powershell -c -
Linux / macOS bash 
curl -fsSL https://kepler.emtypyie.in/curler | bash

Manual Setup

Windows powershell 
curl -L -o kepler-backend.zip ^
  https://github.com/emtypyie/kepler/releases/latest/download/kepler-backend-v2.0.0.zip
powershell Expand-Archive kepler-backend.zip -DestinationPath .
cd kepler-backend
npm install
node server.js
Linux / macOS bash 
curl -LO https://github.com/emtypyie/kepler/releases/latest/download/kepler-backend-v2.0.0.zip
unzip kepler-backend-v2.0.0.zip
cd kepler-backend
npm install
node server.js

Auto-Start

Configure Kepler to launch automatically when your system boots.

Windows powershell (admin) 
powershell -ExecutionPolicy Bypass -File setup\windows.ps1
Linux bash 
sudo ./setup/linux.sh
macOS bash 
./setup/macos.sh

Verify Installation

Once the server is running, confirm it works:

curl http://localhost:41783/api/health
{"status":"ok","version":"2.0.0","port":41783,"services":["ediary","pyieos"]}
