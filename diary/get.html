Download Kepler Backend

Run the backend locally to use ediary, pyieOS, and all Kepler services.

Prerequisites

  • Node.js v18 or later — Download
  • npm (ships with Node.js)

Quick Start

Windows

git clone https://github.com/emtypyie/kepler.git
cd kepler/backend
npm install
node server.js

Then open kepler.emtypyie.in in your browser.

Linux / macOS

git clone https://github.com/emtypyie/kepler.git
cd kepler/backend
npm install
node server.js

Then open kepler.emtypyie.in in your browser.

Auto-Start (Optional)

Configure Kepler to launch automatically when your system boots.

Windows (PowerShell as Admin)

powershell -ExecutionPolicy Bypass -File backend\setup\windows.ps1

Linux

chmod +x backend/setup/linux.sh
sudo ./backend/setup/linux.sh

macOS

chmod +x backend/setup/macos.sh
./backend/setup/macos.sh

Verify It's Running

Once the server is running, check the health endpoint:

curl http://localhost:41783/api/health

Expected response:

{"status":"ok","version":"2.0.0","port":41783,"services":["ediary","pyieos"]}
