Quick Install (Windows)

Download setup.bat from the repo, double-click, and it handles everything:

curl -L -o setup.bat https://raw.githubusercontent.com/emtypyie/kepler/master/setup.bat
setup.bat

The installer checks for Node.js, downloads the latest backend, installs deps, and starts the server.

Manual Setup

Windows

curl -L -o kepler-backend.zip ^
  https://github.com/emtypyie/kepler/releases/latest/download/kepler-backend-v2.0.0.zip
powershell Expand-Archive kepler-backend.zip -DestinationPath .
cd kepler-backend
npm install
node server.js

Linux / macOS

curl -LO https://github.com/emtypyie/kepler/releases/latest/download/kepler-backend-v2.0.0.zip
unzip kepler-backend-v2.0.0.zip
cd kepler-backend
npm install
node server.js

Auto-Start (Optional)

Configure Kepler to launch automatically when your system boots.

Windows (PowerShell as Admin)

powershell -ExecutionPolicy Bypass -File setup\windows.ps1

Linux

chmod +x setup/linux.sh
sudo ./setup/linux.sh

macOS

chmod +x setup/macos.sh
./setup/macos.sh

Verify

Once running, check the health endpoint:

curl http://localhost:41783/api/health

Expected:

{"status":"ok","version":"2.0.0","port":41783,"services":["ediary","pyieos"]}
